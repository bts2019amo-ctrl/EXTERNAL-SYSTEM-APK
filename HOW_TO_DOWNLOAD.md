# Como baixar o APK

O APK está disponível neste repositório.

1. Baixe o arquivo `EXTERNAL-SYSTEM.apk.b64`
2. Decodifique com:
   ```bash
   base64 -d EXTERNAL-SYSTEM.apk.b64 > EXTERNAL-SYSTEM.apk
   ```
3. Instale o APK no celular.

**Link do repositório:** https://github.com/bts2019amo-ctrl/EXTERNAL-SYSTEM-APK

O arquivo binário completo está sendo processado.
